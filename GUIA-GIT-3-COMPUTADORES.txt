GUIA PARA TRABAJAR DESDE TRES COMPUTADORES
Repositorio: https://github.com/astavera/storeonline.git
Rama de trabajo: agent/phase-0-storefront-foundation


============================================================
1. PRIMERA VEZ EN UN COMPUTADOR NUEVO
============================================================

Si todavia no tienes el proyecto en ese computador:

git clone https://github.com/astavera/storeonline.git
cd storeonline
git fetch origin
git switch --track origin/agent/phase-0-storefront-foundation


Si el proyecto ya esta descargado en ese computador:

cd storeonline
git fetch origin
git switch --track origin/agent/phase-0-storefront-foundation
git pull --rebase

Nota: si la rama ya existe localmente, usa:

git switch agent/phase-0-storefront-foundation
git pull --rebase


============================================================
2. ANTES DE EMPEZAR A TRABAJAR
============================================================

Siempre descarga primero los cambios realizados desde los otros computadores:

git switch agent/phase-0-storefront-foundation
git pull --rebase


============================================================
3. AL TERMINAR DE TRABAJAR
============================================================

Revisa los cambios:

git status

Agrega los archivos que deseas guardar:

git add nombre-del-archivo

Para agregar todos los cambios del proyecto:

git add -A

Crea un commit con una descripcion clara:

git commit -m "Descripcion breve del progreso"

Sube el progreso a GitHub:

git push


============================================================
4. RUTINA RESUMIDA
============================================================

ANTES DE TRABAJAR:

git pull --rebase

AL TERMINAR:

git status
git add -A
git commit -m "Descripcion breve del progreso"
git push


IMPORTANTE:
- Ejecuta git pull --rebase antes de comenzar en cualquier computador.
- Ejecuta git push antes de cambiar a otro computador.
- No trabajes simultaneamente en dos computadores sin subir primero los cambios.
- Si Git indica un conflicto, no borres archivos ni fuerces el push. Resuelve el conflicto antes de continuar.
