# Holidays

Holidays are editable website campaigns under `/holidays` and `/holidays/[slug]`.

Each holiday supports slug, title, short title, descriptions, hero copy, SEO, hero image, mobile hero image, accent token, custom accent color, start date, end date, active state, visibility, sort order, layout preset, product grid preset, and product card variant.

Initial examples live in `src/config/holidays.config.ts`:

- Valentine's Day
- Graduation
- Halloween
- Christmas

The admin will later add Easter, Mother's Day, Thanksgiving, Hanukkah, New Year's, and other campaigns without changing routes.
